# Frontend preview fixtures

The SVG illustrations are local sample artwork for the AI Studio frontend preview; they are not AI model outputs.

`botanical-sample.mp4` is the CC0 flower sample served by MDN interactive examples:
https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4

Simulated generation reuses these fixtures regardless of the entered prompt. No provider is called and no charge is incurred.
